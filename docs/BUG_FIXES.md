# Bug Fixes / 修复记录

## 2026-10-20 · 绅士漫画 · 搜索误判为详情页

- 现象：搜索页被误判成详情页，最终只剩 1 条/异常结果。
- 根因：`bookUrlPattern` 过宽，命中了 `/search` 等列表路由，导致阅读底层在搜索阶段提前执行详情页解析。
- 修复：将 `bookUrlPattern` 收紧，只匹配真正的单本详情页路径（如 `/photos-...`、`/albums-...`、`/comment-...`），不再包含 `/search`。
- 关联文档：[`绅士漫画_搜索误判_修复.md`](绅士漫画_搜索误判_修复.md)
- 关键经验：`bookUrlPattern` 必须只覆盖单本详情页，不要含搜索页/列表页；搜索页必须维持 `searchUrl` 与 `ruleSearch.bookList` 正常链路。
