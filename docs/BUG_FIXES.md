## 2026-10-22 · 禁漫天堂 · 纯净正文目录与评论动态抓取修复

- **现象**：目录尾部被硬编码追加非正文章节「💬 读者讨论与精彩评论」；作品简介无法展示真实书友评论（恒定提示未抓取到评论）。
- **根因**：
  1. 目录规则硬编码假章节 `#comments`，破坏阅读章节目录纯净性，干扰全书离线缓存与自动翻页；
  2. 禁漫天堂网页版对评论采用前端 AJAX 异步懒加载（`/ajax/album_pagination`），初始详情页静态 HTML 未直接内嵌评论，正则直接截取静态 HTML 必然落空。
- **修复**：
  1. 剔除目录规则追加的评论伪章节，同时精简正文解析中无用的 `#comments` 判断，保持正文目录干净；
  2. 作品简介规则中引入双层获取逻辑：优先本地正则秒开，落空时通过 `java.ajax` 主动调用官方异步分页接口获取真实评论；
  3. 在“源登录”界面新增「简介展示评论条数」配置选项（5/10/15/20/30/50条，默认10条），支持动态读取生效。
- **关联文档**：[`禁漫天堂与高防漫画站书源实战避坑指南.md`](禁漫天堂与高防漫画站书源实战避坑指南.md#十二功能与体验优化纯净正文目录与评论动态异步抓取) 第十二节

## 2026-10-20 · 绅士漫画 · 搜索误判为详情页

- **现象**：搜索页被误判成详情页，最终只剩 1 条或全空异常结果。
- **根因**：`bookUrlPattern` 正则过宽，命中了 `/search` 等列表路由，导致阅读底层在搜索阶段执行 `baseUrl.matches(bookUrlPattern)` 时提前走单本详情页解析，跳过 `ruleSearch.bookList`。
- **修复**：将 `bookUrlPattern` 收紧，只匹配真正的单本详情页路径（如 `/photos-...`、`/albums-...`、`/comment-...`），不再包含 `/search`。
- **关联文档**：[`实战案例集-歌书网_起点图网_绅士漫画.md`](实战案例集-歌书网_起点图网_绅士漫画.md#案例三绅士漫画--搜索页误判为详情页与结构适配) 案例三
- **关键经验**：`bookUrlPattern` 必须只覆盖单本详情页，严禁包含搜索页/列表页；搜索页必须维持 `searchUrl` 与 `ruleSearch.bookList` 正常链路。
